# ChatGPT Usage 1.0.0

First public release.

## Highlights

- Adaptive Android home-screen widgets with 1×1, 2×2, 4×3 and 4×4 starting sizes.
- Weekly remaining usage, reset dates, available reset credits and prepaid credit balance.
- System, light and dark themes with a monochrome interface.
- One-time-code sign-in and automatic OAuth token renewal.
- Configurable background refresh, 13 date formats and 12/24-hour clocks.
- Manual reset activation with confirmation and persistent retry IDs.
- Consistent in-app dialogs and refresh indicators.
- English default interface with a complete Russian translation and per-app language support on Android 13+.
- Direct API data retrieval; no WebView data scraping or link to the Usage website in the app.

## Installation

Requires Android 8.0 or later. Install the signed APK, sign in, then add a widget from the app or your launcher's widget picker.

Early development APKs were signed with a debug key. Android cannot install the signed release over those builds if their package name is the same: remove the old development build first, then sign in again. New debug builds use a separate `.debug` package.
